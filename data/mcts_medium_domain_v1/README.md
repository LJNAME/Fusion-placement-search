采用本次讨论的阈值：跨度<0.1%为不可区分，>1%为有成本区分度，中间区间单列。四个非空 Joint 可行域均>1%；75%档为空，不能记为跨度0或退化。90%档仅6/144（4.1667%）方案在最优值1%以内，0.1%以内也为6个。

“整个可行域近乎等价”的解释不受本批数据支持。全域成本有区分度，不代表搜索一定困难，也不证明联合优化有收益。Joint/Sequential 的 Exact 最优成本相同，只说明本例最优点成本重合。

当前不启动92%/95%/97%容量扫描；90%档已有144个可行方案且跨度121.7004%，满足“可行数≥2、跨度>1%”的条件。后续若新增容量，仅能作为开发诊断，不能看结果挑成独立测试。
