## 1. 数据与规则

只使用silu_mul_additivity_20261101_150818四臂同批，4case×8轮，原始数据与冻结采集协议verify通过，输入文件SHA读前后不变。六臂数据未加入标签表。测量契约b0b0cd8a…，数据conditional_dev，不绕过模型入口的正式准入闸门。

三可揭示对象为silu/mul/fused，chain只属于评价器。mask的bit0/1/2依次代表S/M/F，1=可见；单次动作只替换目标Key，不refit、不跑MCTS或SROP acquisition。模型只接收三Key先验及可见标签；评价器始终用本case固定的融合/链时间中位数。逐轮敏感性仅改可见标签，也不改变评价器。

C假设先把解析launch设为3.2μs，重新计算全部三个Key的解析值，再仅对隐藏融合Key乘0.5/1/1.5；可见标签不受倍率影响。3.2不是已识别的launch标定，C不是B，也不是概率分布或经验置信区间。C结果不计同契约SROP实证收益。
